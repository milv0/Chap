# Chap 2.0.1

A reliability update for Keep Mac Awake.

## Fixed

- **Keep Awake ends on time across sleep** — A session that runs out while the
  Mac is asleep, for example with the lid closed overnight, now ends as soon as
  the Mac wakes or the status menu opens. The status icon returns to its normal
  color instead of staying blue.
- **Quiet expiry after sleep** — A session that already expired during sleep is
  released without the end-of-session sound or HUD.

## Website

- The Chap site's notch demo is now interactive: hover or tap the notch, press
  an Option shortcut to see a window land centered, drop a file into Chap Drop,
  and follow an optional four-step guided tour.

## Notes

- macOS 14.0+ is required. No configuration changes; existing settings carry
  over unchanged.
