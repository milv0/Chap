# Chap 2.21.0

## New

- **Notch Glow** — When Keep Awake or a timer starts, the notch lights up for a
  moment with soft, flowing color, even while the dock is closed. The dock
  glows the same way while you drag files onto it.
- **Pick the glow** — Choose Colorful or Chap Blue, or turn the glow off, in
  Settings → Notch → Notch Style. Changing it shows the glow once so you can
  see it. It stays off when Reduce Motion is on.
