# Chap 2.19.6

## Fixed

- **Follow Cursor makes the choice clear** — While Follow Cursor is on, the
  fixed Display picker is disabled. You can still click a screen in Preview to
  set that screen's window size.
- **Independent settings save independently** — An unfinished or invalid
  launcher draft no longer blocks changes made in General, Notch, or Tools, and
  those changes no longer save the draft by accident.
- **Layouts stay stable while updating** — A layout being opened or updated
  temporarily locks its name and window assignments until the operation ends.

## Changed

- **Set up the notch before turning it on** — Slots, screenshot folder, notch
  icons, and Appearance remain available while the Notch Launcher is off. Live
  appearance previews wait until you turn it on.
