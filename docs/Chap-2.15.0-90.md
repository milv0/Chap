# Chap 2.15.0

## Added

- **Launchers slot** — One notch slot now holds Sites, Apps, and Finder. Switch
  with the icons at the right of its title; Chap remembers the last one. With it,
  every widget fits in the six slots. The roomier slot keeps names and shortcut
  keys apart, and it doesn't change size when you switch. Separate Sites, Apps,
  and Finder slots still work as before.
