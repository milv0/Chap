# Chap 1.0.6

## What's New

- **Clearer site setup flow** — The Settings form now puts the site name first, followed by launch type and its URL, app, folder, or script target. The shortcut comes next, with display and window-size controls following for URL, App, and Finder launches.
- **Improved name emphasis** — Site names use a larger, semibold entry field so each shortcut is easier to identify while configuring it.

## Improved

- **Focused configuration by launch type** — Shell launches end after their target and shortcut because they do not use window placement. URL, App, and Finder launches retain their existing display, Follow Cursor, size-preset, custom-size, and minimap controls.
- **Updated product walkthrough** — The Chap homepage now previews the same settings workflow used in the app.

## Notes

- Existing URL, App, Finder, and Shell configurations continue to work unchanged.
- Existing automatic naming, reserved-shortcut validation, and script-editor behavior are preserved.
- macOS 14.0+ required. Chrome required for URL launch type.
