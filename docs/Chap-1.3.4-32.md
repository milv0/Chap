# Chap 1.3.4

## Improved

- **Quieter Keep Awake start sound** — Switched the session-start sound from
  Glass to the softer Purr.
- **Leaner status bar menu** — Removed Restart from the menu bar list;
  it remains available from the settings window's ⋯ menu.
- **Clearer tab name** — Renamed the "Launchables" settings tab to
  "Launchers".

## Notes

- macOS 14.0+ required. Chrome required for URL launch type.
