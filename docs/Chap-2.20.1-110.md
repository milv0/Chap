# Chap 2.20.1

## Changed

- **Simpler launcher editing** — The editor no longer shows a URL, App, or
  Finder picker. The section title names the type, and App launchers show the
  app's own icon there.
- **Notch settings fit on one screen** — Notch Icons and the screenshot folder
  now share one group, so the tab no longer needs scrolling.
- **A tidier window size** — Settings opens a little shorter, sized to fit the
  longest tab.
