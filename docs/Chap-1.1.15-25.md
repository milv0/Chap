# Chap 1.1.15

## Improved

- **Deliberate Shell editing** — For Shell launchables, clicking inside the
  script editor is now the only way to re-enter edit mode after saving.
  Clicking elsewhere in the saved configuration panel no longer enables
  editing, preventing accidental edits to saved scripts.
- **Unchanged for other types** — URL, App, and Finder launchables still enter
  edit mode from a click anywhere in the panel.

## Notes

- macOS 14.0+ required. Chrome required for URL launch type.
