# Chap 2.8.4

## Changed

- **Pixel seal app icon** — The app icon is now Chap the Seal drawn as pixel art,
  resting on a thin waterline, so the icon and the seal beside the notch are the
  same character.
- **Chap in the Focus HUD** — The center overlay for Keep Awake shows the seal
  instead of a coffee cup: awake with its tail up when Focus starts, asleep with
  a z when it ends.
- **Max fills the height** — The Max size preset now uses the full visible
  height, so a Max window has no gap above or below (width stays at 94%).
