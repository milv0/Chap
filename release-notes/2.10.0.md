# Chap 2.10.0

## Changed

- **Settings, reorganized** — General keeps only what is about the app itself
  (Startup, Shortcuts, Menu Bar). Notch keeps only how the notch looks (Launcher,
  Layout, Top Strip icon switches, Appearance). A new Tools tab holds each
  feature's own settings: the Quick Note shortcut and a Backups button, the Lights
  Out shortcut and unlock key, and the Mirror's camera privacy link. Every row now
  shares one shape, with longer help in tooltips.
- **⌥N works without the notch** — The Quick Note shortcut no longer depends on
  the notch launcher or its strip icon being on; clear the key to turn it off.
