# Chap 2.14.0

## Added

- **Timer** — Start a countdown from Timer in the status menu (5 minutes to an
  hour) or from a new notch Timer slot (5-minute steps, up to 3 hours). While it
  runs and the notch is closed, the time left sits just left of the notch. When
  it ends, Chap plays a sound and shows "Time's up". One timer at a time; it
  lives in memory only and doesn't keep the Mac awake.

## Fixed

- **Undo in Quick Note** — ⌘Z undoes and ⇧⌘Z redoes typing in Quick Note, the
  To-do list, and Settings text fields. Chap's hidden Edit menu had no Undo or
  Redo, so the shortcuts did nothing.

## Changed

- **Q&A: apps on another desktop** — Explains why a workspace can't move windows
  between desktops (Spaces) and how to assign an app to This Desktop or All
  Desktops from its Dock icon.
