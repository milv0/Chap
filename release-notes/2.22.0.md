# Chap 2.22.0

## Added

- **Glow for new files** — The notch lights up once when a new screenshot or
  download lands in a shelf on the notch, or when you add files to Chap Drop.
- **Glow for windows** — The notch gives a short glow when a launcher or a
  layout puts a window in place.
- **Choose when it glows** — Turn either one off under Settings → Notch →
  Notch Style → Also Glow When.

## Changed

- **Notch Glow lights up and lets go** — The notch no longer stays lit while
  Keep Awake or a timer runs. It glows once when either starts or ends, and a
  little brighter and longer when a timer finishes. If the dock is open, the
  glow waits until it closes.
