## Improved

- **Clearer site configuration order** — Launch Type appears first, followed by Name and Shortcut on one row, then the launch-specific target input.
- **Focused Shortcut input** — The centered 88pt Shortcut input uses a subtle blue surface and border without changing the surrounding form layout.
- **Consistent launch setup** — URL, App, Finder, and Shell use the same compact configuration pattern; the App chooser remains beside the App-path input.
- **Updated product page** — The GitHub Pages settings preview now reflects the current configuration layout and input-only Shortcut emphasis.

## Notes

- Shortcut entry still accepts one character, normalizes it to uppercase, and prevents the reserved `.` and `,` keys.
- Shell configuration continues to omit window sizing controls.
- macOS 14.0+ required. Chrome required for URL launch type.
