## What's New

- **Option-key trigger control** — General settings can disable all Chap Option-key triggers when another workflow needs the Option key, without removing configured shortcuts.
- **Focused settings navigation** — Launchables and General now switch from a compact bottom control while the site sidebar remains visible.
- **Status bar icon settings** — Choose the default Chap icon or the lightning icon directly from General settings.

## Improved

- Selecting a site from General returns directly to its Launchables configuration.
- Status bar icon controls and the menu bar button use explicit vertical centering.
- Existing configurations remain compatible and keep Option-key triggers enabled by default.

## Notes

- Disabling Option-key triggers affects `Option+.`, `Option+,`, and configured site shortcuts.
- macOS 14.0+ required. Chrome required for URL launch type.
