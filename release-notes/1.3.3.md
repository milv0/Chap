# Chap 1.3.3

## Added

- **Keep Awake icon indicator** — With the Lightning status bar icon, the
  bolt now turns Chap's theme blue while a Keep Awake session is active,
  making it easy to tell at a glance whether the display will stay awake.
  It returns to normal automatically when the session ends or expires.

## Notes

- The indicator applies to the Lightning icon only; the Default icon is
  unaffected.
- macOS 14.0+ required. Chrome required for URL launch type.
