# Chap 2.9.4

## Changed

- **Switch and shortcut on one row** — In Settings → Notch → Top Strip, Quick
  Note and Lights Out each fit on one row: title and a short note, then ⌥ and the
  key, then the switch. Lights Out's ⌥ key can now be changed there too.
  Turning the Lights Out icon off keeps ⌥L working.
- **Tidier key boxes** — The one-letter key boxes no longer stretch or push the
  letter off center.
