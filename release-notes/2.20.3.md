# Chap 2.20.3

## Changed

- **A Mac-style Settings window** — Launchers, General, Notch, and Tools now sit
  in the standard settings toolbar, each with its icon above its name, and the
  window title shows the tab you're on.
- **Help and app actions moved to General** — User Guide, Q&A, and More
  (import, export, Report Bug, Restart, Uninstall) now sit next to the version
  at the bottom of General. ⌘/ still opens the guide from any tab.
