# Chap 2.13.0

## Added

- **Workspaces (demo)** — Arrange your app windows, choose **Workspaces → Capture Workspace…**, and name the layout. Open it again from the status menu or the new Workspaces notch widget, and Chap brings each app back to the display, size, and position you left it in. Up to four workspaces of six windows each. Windows Chap can't identify for certain are skipped, not guessed. App names, window titles, and positions stay in a local file on this Mac and are not part of config export.
