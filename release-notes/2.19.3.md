# Chap 2.19.3

## Added

- **Window sizes by shape** — Size presets are now a grid of window-shape
  thumbnails: a landscape row and a new portrait row with Sidebar, Tall,
  Document, and Half. Hover a shape to see it in the preview, click to use it.
  Focus left the list; items already using it keep the same size.

## Changed

- **Tidier launcher settings** — Display, Follow Cursor, Reuse Existing Window,
  and Size now sit together under Window, and the preview is a single box.
  Inputs are shorter, and layouts follow the same look.
- **Screenshot folder moved** — It now lives in Settings → Notch → Screenshots,
  next to the shelf that uses it.

## Fixed

- **Settings tabs no longer overlap** — Shrinking the Settings window stops
  before the bottom tabs cover the ? and ⋯ buttons.
