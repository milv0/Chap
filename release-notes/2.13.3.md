# Chap 2.13.3

## Added

- **Workspaces in Launchers** — Settings → Launchers has a Workspaces section below URL, App, and Finder. Select a workspace to rename it, see its windows laid out on each display, move a window to another display, leave one out, open it, or delete it. Edit Workspace in the menu and the notch opens this page.
- **Update Positions** — Arrange a workspace's apps again and save where their windows are now, without capturing a new workspace.
