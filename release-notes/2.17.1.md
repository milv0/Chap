# Chap 2.17.1

## Changed

- **Workspaces are now Layouts** — The feature that saves and restores your
  window arrangement is called Layouts everywhere: the notch tab, the status
  menu (Layouts → Capture Layout…), and Settings. Nothing to redo: your saved
  layouts and the last tab you picked carry over, and the file moves to
  `Layouts.json` on first launch. The Workspace window size stays as it is.
- **Lighter Layouts tab** — Layout icons are now the same size as the app icons
  on the Apps tab and sit closer together, with a little more room between rows.
  Long names are shortened; point at a tile to see the full name. Together with
  the shorter tab name, this makes the Apps slot narrower.
- **Clearer headings** — Settings → Notch → Layout is now **Slots**, and a
  layout's display map is headed **Preview**, so neither is mistaken for the
  feature.
