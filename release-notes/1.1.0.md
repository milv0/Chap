## Added

- **Optional URL window reuse** — Each URL launchable can bring forward an existing Chrome window showing the same URL instead of opening another window.
- **Focused-window placement** — Reused Chrome windows are activated and moved to the configured display and size using verified Accessibility bounds.
- **Chap product story** — The website now explains how Chap's seal-inspired name connects fast movement with fast Option-key access.

## Improved

- **Roomier settings window** — The default Settings height is increased so the new URL option fits without adding unnecessary scrolling.

## Notes

- URL window reuse is off by default, preserving the existing new-window behavior.
- macOS may request permission to control Google Chrome when URL window reuse is first used.
- macOS 14.0+ required. Chrome required for URL launch type.
