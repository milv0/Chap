# Chap 1.0.8

## Improved

- **URL site settings** — The URL and Shortcut fields now share a row for URL launch types. The URL keeps most of the available width, while Shortcut uses a compact dedicated field.

## Notes

- App, Finder, and Shell settings retain their existing full-width Shortcut field.
- Existing shortcut validation and reserved-key protection are unchanged.
- macOS 14.0+ required. Chrome required for URL launch type.
