# Chap 2.20.0

## Changed

- **A tidier Settings window** — Launchers, General, Notch, and Tools now sit in
  a centered bar at the top. The launcher list appears only on the Launchers
  tab, so the other tabs get the full width.
- **Resize Settings freely** — The window opens a little taller and can shrink
  to 720 × 560 or grow in any direction. The scroll bar sits at the right edge.
- **Launcher editing is calmer** — Type, name, target, shortcut, display, size,
  and preview now share one simple layout. Changes save as you type.
- **Notch settings are more compact** — Slots sit in one row in notch order.
  Notch icons are small buttons beside their title, and changing one shows the
  notch for a moment. Appearance is now called Notch Style.
- **Import brings everything back** — Importing a config restores all four tabs,
  and Chap asks before replacing changes you haven't saved.

## Fixed

- **Typed sizes stay put** — Picking a preset or another display no longer saves
  a width or height you were still typing.
