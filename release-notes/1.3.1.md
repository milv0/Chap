# Chap 1.3.1

## Improved

- **Keep Awake feedback** — Starting or stopping a Keep Awake session now
  shows a brief coffee-cup overlay in the center of the screen with a subtle
  sound, including when a session expires on its own.
- **Compact menu settings** — The menu section visibility controls in
  Settings > General are now a single row of URL / App / Finder / Shell
  chips instead of four separate toggles.

## Notes

- macOS 14.0+ required. Chrome required for URL launch type.
