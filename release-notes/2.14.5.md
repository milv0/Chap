# Chap 2.14.5

## Fixed

- **Typing in Quick Note** — Quick Note takes your typing and Esc again. In
  2.14.4 the new window couldn't receive the keyboard, so the note stayed empty
  and Esc did nothing.

## Changed

- **Rounded Quick Note** — The Quick Note card has the same soft corners as a
  macOS window, with a light outline and a shadow that follows them.
- **Badges that match the notch** — The Timer and Drop badges beside the notch
  now curve like the notch itself, and the seam where they meet it is gone.
