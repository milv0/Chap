# Chap 1.3.6

## Fixed

- **Clearer empty shortcut field** — The compact Shortcut field now shows a
  dash ("–") instead of the letter "T" when no shortcut is set, so it's not
  mistaken for an assigned value. The letter was only a placeholder; unset
  shortcuts never launched anything.

## Notes

- macOS 14.0+ required. Chrome required for URL launch type.
