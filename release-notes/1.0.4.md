## What's New

- **Status bar icon selection** — An "Icon" submenu in the menubar menu lets you switch between Default (custom template) and Lightning (SF Symbols bolt.fill). The choice takes effect immediately, persists in `~/.chap.json` as `statusBarIcon`, and defaults safely to Default when the field is absent. The Accessibility-denied warning icon is unaffected.

## Improved

- **Shortcut–site mapping clarity** — English and Korean landing-page copy now says users press their configured shortcut, replacing the previous wording that referred to pressing a letter.

## Notes

- Existing `~/.chap.json` files without `statusBarIcon` continue to work unchanged (Default icon).
- macOS 14.0+ required. Chrome required for URL launch type.
