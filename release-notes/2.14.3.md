# Chap 2.14.3

## Changed

- **Quick Note, more Chap** — Quick Note now uses a Chap Glass window surface
  while keeping the familiar macOS traffic lights, resizing, and window drag.

## Fixed

- **Shortcut conflicts** — A launcher shortcut can no longer take a key assigned
  to Quick Note or Cover Screens. Chap keeps the previous launcher key and shows
  a red explanation; the same rule also protects saved and imported settings.
