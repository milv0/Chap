# Chap 1.1.14

## Fixed

- **Dark Mode Shortcut field** — The Shortcut input in site settings is now
  readable in Dark Mode; its highlight adapts to the system appearance instead
  of using a fixed light color.

## Added

- **Minimum window size notice** — When a launched app enforces a minimum
  window size larger than the configured size, Chap now explains why the size
  was not applied and shows the app's minimum. The notice appears once per
  launchable and size combination per session.

## Notes

- macOS 14.0+ required. Chrome required for URL launch type.
