# Chap 2.22.3

## Changed

- **Shorter start and end glow** — The notch glow when Keep Awake or a timer
  starts or ends is now briefer (1.4 and 1.1 seconds), since the sound and
  center message already confirm it. A finished timer still glows longest.
- **Preview matches the real glow** — Changing the glow color in Settings now
  shows the same length as a start glow, and goes around the Drop or timer
  badge when one sits beside the notch.
- **One glow per Drop** — Adding files to Chap Drop no longer glows the notch
  again after you let go. The dock already glows while you drag them in.
