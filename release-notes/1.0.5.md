## What's New

- **Manual update checking** — A new "Check for Updates…" menu item lets you check for app updates on demand. Chap uses [Sparkle 2](https://sparkle-project.org/) (pinned at 2.9.6) with EdDSA signature verification. No automatic background checks or permission dialogs occur; updates are triggered exclusively by user action.

## Architecture

- **Fail-closed updater** — The updater starts only when both `SUFeedURL` (HTTPS) and `SUPublicEDKey` are present and valid in Info.plist. If either value is missing or malformed, the menu item is disabled and no network requests are made.
- **EdDSA verification** — Update packages are verified against the embedded ed25519 public key. The private key lives only in the operator's Keychain and is never included in the app.
- **No automatic checks** — `SUEnableAutomaticChecks` is `false`; starting the updater never schedules background polls or shows Apple's automatic-check permission prompt.

## Build Tooling

- **Appcast generation** — `Scripts/generate-appcast.sh` signs notarized DMGs with the Sparkle CLI, validates the XML feed (well-formedness + required enclosure attributes), and places the result at `docs/appcast.xml` for GitHub Pages. The release script invokes it automatically when `SPARKLE_BIN_DIR` or `SPARKLE_GENERATE_APPCAST` is set.

## Notes

- The initial `docs/appcast.xml` is an empty feed. The first real update entry will be generated when v1.0.5 is published with `--publish` and Sparkle CLI is available.
- End-to-end update download/install will be validated after the notarized DMG is deployed to a GitHub Release with a signed appcast entry.
- macOS 14.0+ required. Chrome required for URL launch type.
