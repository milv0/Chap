# Chap 2.19.4

## Fixed

- **Mirror turns off when it closes** — Closing the Mirror during its first
  camera connection can no longer let the camera start again in the background.
  Quickly reopening it also keeps the new preview running.
- **Quick Note saves what you see** — Opening a note no longer rewrites it, and
  rapid typing, deleting, or undoing cannot let an older save overwrite the
  latest text or show Saved too early.

## Changed

- **Lighter screenshot scans** — Chap filters files before reading their dates,
  reducing work when the screenshot folder contains many other files.
- **Clearer Settings controls** — Toolbar icons now have proper VoiceOver names
  and actions.
- **Housekeeping** — Removed unused design and website assets and brought the
  guide, architecture, flow, and permission copy in line with current behavior.
